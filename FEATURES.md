# Feature Coverage Matrix (FEATURES.md)

> **Source of Truth** for feature implementation, verification, and audit coverage across the Vitarak FMCG Platform.
> Last updated: November 25, 2026.
> 
> **Status Definitions**:
> - `Built and visible`: Screen exists, is reachable directly from active UI navigation, and is covered by automated tests.
> - `Built backend only`: Working schema, service logic, and API routes exist; dedicated UI screen is pending or runs as an automated background script.
> - `Partial`: UI exists but lacks certain planned interactive controls or deep analytics filters.
> - `Not started`: Planned for a specific future phase (Phase 4, 5, or 6); specification agreed.
